**AstroCare Module 18/21:** A mission simulation and biomedical readiness platform engineered for human deep space exploration missions.

> **Operational Notice:** All simulation outputs are generated by deterministic mathematical surrogate models. They are designed for mission planning, education, and decision-support demonstrations. They are not validated NASA mission operations models and are not intended for clinical decision-making.

---

## 🌟 Key Capabilities

1. **Deterministic Simulation Engine:** Time-stepped engine with start, pause, resume, reset, single-stepping, and speed multipliers ($1\times, 2\times, 10\times, 60\times, 300\times$).
2. **Ten Predefined Scenarios:**
   - **S01 — Nominal Mission Operations:** Stable baseline parameters.
   - **S02 — Solar Particle Event (SPE):** High-energy proton flux with storm shelter ingress.
   - **S03 — Cabin Pressure Anomaly:** Micrometeorite hull leak with suit donning and repair protocols.
   - **S04 — Hypoxia Emergency:** Oxygen Generation System (OGS) failure with emergency reserve activation.
   - **S05 — Thermal Regulation Failure:** ATCS pump fault causing heat escalation and power shedding.
   - **S06 — Sleep and Circadian Disruption:** Multi-day extended duty cycles with psychomotor vigilance degradation.
   - **S07 — Communication Blackout:** Deep-space delay and RF failure triggering autonomous decision protocols.
   - **S08 — Equipment Failure:** CDRA CO₂ scrubber malfunction with LiOH chemical backup canisters.
   - **S09 — Medical Emergency:** Acute cardiac arrhythmia event requiring clinical triage and workload reallocation.
   - **S10 — Multi-System Compound Emergency:** Simultaneous SPE, scrubber offline, and comms blackout requiring priority management.
3. **Interactive Scenario Builder:** Create custom mission profiles, tune initial conditions, schedule timed events, and persist custom scenarios to local storage.
4. **Physiology & Environmental Coupling:** Dynamically couples cabin atmosphere ($ppO_2$, $ppCO_2$, temperature, pressure) with astronaut vital signs ($SpO_2$, heart rate, respiration, fatigue, readiness score).
5. **Radiation Physics Distinction:** Rigorously distinguishes between **Absorbed Dose** ($\text{mGy}$) and **Effective Dose** ($\text{mSv}$) while modeling storm shelter mass shielding ($5\text{ g/cm}^2$ vs $25\text{ g/cm}^2$ aluminum equivalent).
6. **Explainable Risk Assessment:** NASA SP-2015-6105-inspired 5×5 Likelihood $\times$ Consequence matrix evaluating Environmental, Radiation, Crew, Resource, and Compound risks with actionable response protocols.
7. **Decision Support & What-If Analysis:** Real-time countermeasure testing with before-and-after trajectory comparison.
8. **Structured Reporting:** One-click simulation report compilation and export to JSON and CSV.

## 🚀 Quick Start

```bash
# Clone or navigate to the repository
cd AstroCare_P18_Mission_Scenarios

# Install dependencies
npm install

# Start development server
npm run dev
# Open http://localhost:3000 in your browser

# Run the Vitest unit test suite (43 tests)
npm test

# Build for production
npm run build
```
